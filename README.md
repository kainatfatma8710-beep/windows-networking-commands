# windows-networking-commands
# Essential Windows Networking Commands

## Overview
This project demonstrates six essential Windows CMD
networking commands used for network configuration,
connectivity testing, DNS lookup, and troubleshooting.

## Commands Covered
- ipconfig
- ping
- tracert
- nslookup
- netstat
- arp

## Purpose
To develop practical networking knowledge and
strengthen IT and Cybersecurity fundamentals.
